# Excel Reports

This folder contains Excel-based tracking tools developed for IT operations reporting.

## Included Workbook

- IT_Operations_Incident_Tracker.xlsx – Tracks incident details, priorities, root causes, corrective actions, resolution status, and incident duration.

## Workbook Features

- Structured incident tracking
- Automated incident duration calculation
- Filterable records
- Organized reporting fields

All incident data is simulated for educational and portfolio purposes.
