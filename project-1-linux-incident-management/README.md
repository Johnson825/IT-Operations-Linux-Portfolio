# Project 1 – Linux Incident Management

This project demonstrates IT incident management, Linux troubleshooting, root cause analysis, incident documentation, and recovery validation using a simulated Linux server outage.

## Project Components

- Incident Reports: Incident investigation, timeline, root cause, corrective actions, and resolution documentation.
- Excel Reports: Incident tracking workbook with automated duration calculations.

## Environment

This is an independent learning project using simulated production incident data. No actual production systems were accessed.
