# Project 1: IT Operations Incident Management

## Project Overview
This project demonstrates an IT operations incident tracking and reporting workflow using Microsoft Excel. The workbook was designed to document incidents, track resolution status, organize operational data, and summarize incident trends through a reporting dashboard.

**Note:** All five incidents in this project are fictional, simulated scenarios created for portfolio and training purposes. They do not represent actual workplace incidents.

## Project Objectives
- Create a structured incident tracking workbook.
- Document incident details, categories, priorities, severity levels, and statuses.
- Track assigned teams and resolution information.
- Use Excel formulas to calculate incident totals and summarize operational data.
- Build charts to visualize incident trends and status.

## Tools and Technologies
- Microsoft Excel
- Excel Tables
- Data Validation
- Conditional Formatting
- COUNTIF and COUNTA formulas
- Excel Charts

## Workbook Features

### 1. Incident Tracker
- Created a structured incident tracking table with unique incident IDs.
- Documented incident dates, titles, categories, priorities, severity levels, and descriptions.
- Tracked incident status, assigned teams, resolution notes, and resolution dates.
- Added dropdown lists to standardize incident classifications.
- Applied conditional formatting to highlight incident priorities.

### 2. Incident Summary Dashboard
- Calculated total incidents using Excel formulas.
- Summarized incidents by priority, category, and status.
- Created a pie chart to visualize incident priority distribution.
- Created column charts to display incidents by category and status.
