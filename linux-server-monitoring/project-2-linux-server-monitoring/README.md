# Linux Server Monitoring, Service Management & Health Check

## Project Overview

This project demonstrates hands-on Linux system monitoring, resource assessment, process inspection, service management, and application health verification.

The work was completed in a LabEx Linux practice environment.

## Skills Demonstrated

- Linux command-line operations
- CPU and memory monitoring
- Disk capacity assessment
- Process inspection
- Service status verification
- Nginx service management
- Network port inspection
- HTTP response validation
- Technical documentation

## Project Files

| File | Description |
|---|---|
| `linux-server-health-check.md` | Documents monitoring results, commands, service checks, and findings. |
| `Linux_Server_Health_Check_Tracker.xlsx` | Spreadsheet tracker for recording system health checks. |

## Environment

LabEx Linux practice container.

**Note:** All observations are from a practice environment and do not represent production infrastructure.

## Project Outcome

Successfully performed Linux health checks, started the Nginx service, and verified its availability through process, port, and HTTP response checks.
