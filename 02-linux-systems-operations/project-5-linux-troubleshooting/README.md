# Project 5: Linux System Monitoring and Troubleshooting

## Project Overview

This project demonstrates practical Linux system monitoring and troubleshooting skills, including checking system resources, reviewing logs, monitoring processes, and investigating common system issues.

## Skills Demonstrated

- Linux system monitoring
- CPU and memory utilization checks
- Disk space and storage monitoring
- Process management
- Log file review
- Service status checks
- Basic troubleshooting and documentation
